## 大阪工業大学 人力飛行機プロジェクトとは

当チームは人力飛行機の研究を目的とした大阪工業大学のプロジェクトチームです。研究成果を発表する場として読売テレビ主催の鳥人間コンテストの人力プロペラ機部門に挑戦しています。
